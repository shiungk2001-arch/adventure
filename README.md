# 勇者學習冒險記

手機友善的學習追蹤 RPG，版本 2.3。所有地圖與角色素材都已包含在 `index.html`。

## 啟用手機網頁

1. 開啟本專案的 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
3. Branch 選擇 **main**，資料夾選擇 **/(root)**，按 **Save**。
4. 等 GitHub 顯示發布完成，點選 Pages 設定頁提供的網站網址。

預期網址為 `https://shiungk2001-arch.github.io/adventure/`；啟用並完成發布後才可使用。

私人專案的 GitHub Pages 需要支援的付費方案，例如 GitHub Pro。如果設定頁要求升級，請由專案擁有人決定是否保留私人並升級，或改為公開後使用免費 Pages。公開專案會公開原始碼與美術素材。請不要把學習資料 JSON 備份上傳到專案。

## 備份與移轉

點選網頁右上角的「備份」，解鎖家長模式：

- **下載 JSON 備份**：下載角色、金幣、經驗、穿戴、背包、學習與考試紀錄、錯題、獎勵券及金幣紀錄。
- **選擇 JSON 檔案**：先查看匯入摘要，確認後取代本機進度。匯入前會保留一份還原資料。
- **還原匯入／清除前的資料**：取回目前瀏覽器保存的上一份還原資料。

家長 PIN 不會放入 JSON，換裝置後可重新設定。資料只保存在各裝置的瀏覽器；網站發布與更新不會自動同步各裝置的進度，也不會將學習資料傳到 GitHub。

從舊的本機 HTML 移轉到網站：先在舊檔下載 JSON，再到網站匯入一次。之後請固定使用同一個網站網址與瀏覽器。請定期下載備份；不要將備份放在公開網站中。

## 功能

- 八個固定大地圖，依評量張數解鎖。
- 像素主角、四欄換裝與 14 件裝備美術。
- 練功、錯題複習、考試成績與圖表。
- 每日裝備商店、稀有寵物、獎勵券。
- JSON 檔案下載、匯入摘要、格式檢查與還原備份。
